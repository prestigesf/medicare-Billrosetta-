The calculation

Every figure is checkable

Medicare pays a code as the sum of three relative value units, each adjusted by its own geographic index, multiplied by a conversion factor. The three indices are not interchangeable — applying one to the wrong component yields a plausible, wrong number. Here is CPT 99214, an established-patient office visit of moderate complexity, in Alabama.

Work 1.92×1.000 =1.9200
Practice expense 2.00×0.875 =1.7500
Malpractice 0.14×0.566 =0.0792
Total RVU 3.7492
× 33.4009 =$125.23

What the real files broke

Every one of these produced a plausible wrong number

None of these appeared against synthetic fixtures. Each surfaced only when an actual CMS release was loaded, and each would have shipped a confident, defensible-looking figure that was wrong.

A CPT code is not unique

Imaging appears three times — global, professional component -26, technical component TC — each with different RVUs. The CY2026 release carries 2,261 such rows. Keyed on the code alone they read as conflicting duplicates.

The whole 19,356-line file was refused on first load. Keyed on code + modifier it now loads, and a professional read prices at $9.54 rather than the $29.60 global service.

MAC plus locality is not unique either

Contractor 05102 serves both Connecticut and Iowa, each as locality 00, with practice-expense indices of 1.122 and 0.900. Contractor 03502 does the same for South Dakota and Utah.

Silently keeping one would have priced Connecticut with Iowa's indices — roughly 20% off on the practice-expense component of every line in the state. The loader refused instead, which is how it was found.

Status governs pricing, not the presence of RVUs

158 non-priceable rows carry real relative value units. CPT 27215 has a work RVU of 10.19 under status I, "not valid for Medicare purposes."

Computed rather than refused, that line yields a substantial benchmark for a service Medicare does not pay under this schedule. Only statuses A, R and T are priced.

The header row moves between releases

The full July release carries nine banner rows; an excerpt of the same file carried eight. A fixed offset reads a banner as the header and every column resolves one row late.

Layouts now locate the header by its first cell. Column positions are proved independently by reconciling parsed components against CMS's own published totals.

A rounded ratio hid a threshold

A charge at 1.504× the benchmark displayed as 1.50 and slipped under a 1.5× flag.

The comparison now uses the exact ratio and rounds only for display.

Coverage and limits

Where this is not the right benchmark

36 of 53 states resolve from the state alone

They contain exactly one locality. CMS does not reliably publish the ZIP-to-locality crosswalk, so the remaining 17 need an explicit locality or a crosswalk.

Professional services only

Hospital facility charges price under OPPS for outpatient and DRGs for inpatient — different systems entirely. Comparing a facility line to the physician fee schedule is the wrong benchmark, and this engine will not pretend otherwise.

One schedule year loaded

CY2026. A rate is only defensible for a date of service the loaded release covers — an appeal on a 2024 bill needs the 2024 schedule. Overlapping periods are rejected outright rather than resolved by guessing.

Nothing is estimated

There is no default rate anywhere in the engine. Every failure names its own reason: unknown code, unmapped ZIP, ambiguous state, not priceable, no schedule for that date, missing practice-expense RVU.

Figures are Medicare allowed amounts computed from CMS published RVU, GPCI and conversion-factor data for CY2026 RVU26C. They are benchmarks, not a determination of what is owed, and nothing here is legal or medical advice. All figures on this page are produced by the engine and reproducible from the committed data.
